Set up recent audio capture on Windows

Audio Capture records audio in the background so you can clip a recent moment with a key press. It is useful for adding a new sound while a game or call is still happening.

  1. Install and configure Voicemeeter Banana. Follow the Voicemeeter setup instructions, including selecting your input and output devices, loading the settings, and enabling Configure system audio.
  2. Enable Audio Capture. Open Config, set Audio Capture to Yes, and choose your capture settings.
  3. Set Capture Key. The default is scroll_lock. This is the key you press to take a clip, rather than the key that will play the finished sound.
  4. Set Audio Clip Duration (Seconds). The default is 3. This controls the length of the captured clip.
  5. Save and start. Click Save, then start the player from Home if it is not running. Wait for KeyboardSoundPlayer is ready before capturing.

Keep Voicemeeter running while Audio Capture is enabled. Capturing audio and sending sounds through your microphone are separate options; enable Output To Mic as well if you want other people in a call to hear your replays.

Queue keys for your next audio clips

Before taking a clip, enter a destination key and press the app's Capture button. This adds the key to the capture queue. You can queue multiple keys in the order you want them filled.

Example: save two moments to two keys

Enter a and click Capture. Then enter b and click Capture again.

Press scroll_lock after the first moment: the clip is bound to a. Press it after another moment: that clip is bound to b.

After each capture, allow roughly 2–3 seconds for processing. Longer clips can take more time. Once processing is complete, press the destination key to replay your clip.

Replay captured audio in a call or game

A captured clip becomes a soundboard binding. You can play it with its assigned key just as you would an MP3 or WAV file bound to a key.

To share the replay through voice chat, set up soundboard microphone output. Your game or chat app needs to receive the Voicemeeter virtual microphone, not just your physical microphone.

Audio capture troubleshooting

What is the difference between Capture and Capture Key?

The Capture button queues the key that will receive a clip. The configured Capture Key takes the clip and assigns it to the next queued key. Set up the queue before pressing your capture key.

Why is my captured sound not ready immediately?

Clips need time to process. Wait a few seconds, especially if you increased Audio Clip Duration, before testing the destination key.

Why does the player ask me to install Voicemeeter?

Audio Capture requires Voicemeeter Banana. Check the Voicemeeter Config tab and make sure Path to Voicemeeter Banana points to voicemeeterpro.exe. Then load the provided settings and restart the player.

How do I return to normal Windows audio?

Turn Configure system audio off before closing Voicemeeter. To run KeyboardSoundPlayer without it, set both Audio Capture and Output To Mic to No in Config and save.
