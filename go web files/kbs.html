KeyboardSoundPlayer

Turn every key into a moment. Bind clips, music, YouTube audio, or text-to-speech and play it instantly in games, streams, and calls.

Get it from Microsoft Store → Explore the documentation

KeyboardSoundPlayer is an application that lets you map audio to any key on your keyboard, turning it into a versatile soundboard. Capture audio on the fly and instantly bind it to a key, or add sounds directly from YouTube links. You can also generate audio from text or load local files such as MP3 and WAV when needed. Keys may be mapped to functions for greater interactivity, and audio can be set up to play through your microphone, making it ideal for streaming, gaming, or calls.

Starting, Restarting, and Errors

On Home, click Start to start KeyboardSoundPlayer. The progress bar shows how much has loaded; wait for KeyboardSoundPlayer is ready before playing sounds. Use the restart button between Start and Stop to restart the player. While it restarts, the status says Restarting KeyboardSoundPlayer....

Saving or resetting Config also restarts the player if it is already running. The progress bar appears above the configuration fields so you can see the restart status.

If you see Voicemeeter needs to be installed for your current configuration, follow the Voicemeeter setup instructions. The error message includes a link to the Voicemeeter Config tab in the app and a website link for more help.

Errors clear automatically when you switch pages in the app. You can also click Dismiss if the player fails to start or restart.

Keys

In the main window, there are four buttons for binding sounds to keys:

  • YouTube URL: Bind a sound from a YouTube video
  • Audio File: Select and bind an MP3 or WAV file
  • Text: Enter text to generate and bind audio, or trigger a function
  • Capture: See more details in the Audio Capture section

See below for how to map a function to a key.

Functions

Functions can be bound to specific keys. Available functions include:

reset(): Clear all of the audio channels
toggle(): Toggle the sound player (disables all commands if toggled off)
pause(): Pause all sounds
unpause(): Unpause all sounds

Voicemeeter Setup for Mic Output and Audio Capture

To use Output To Mic or Audio Capture, install and configure Voicemeeter Banana. You can install it from the Voicemeeter Config tab in KeyboardSoundPlayer:

  1. Install Voicemeeter Banana. Open Voicemeeter Config from the app's menu, click Download, and complete the installer. Restart your computer after installation.
  2. Enable the features you want. Open Config, set Output To Mic and/or Audio Capture to Yes, and click Save.
  3. Select your microphone and speakers. Return to Voicemeeter Config. Choose your microphone under Input Device and your speakers or headphones under Output Device. These selections save automatically.
  4. Check the Voicemeeter path. If Path to Voicemeeter Banana is blank or incorrect, click Select Path and choose voicemeeterpro.exe from your installation folder.
  5. Copy and load the settings. Click Copy Settings Path, then Open Voicemeeter. In Voicemeeter, open Menu, select Load Settings on Startup, paste the copied path, and open the file. Restart Voicemeeter to load those settings.
  6. Turn on Configure system audio. In KeyboardSoundPlayer's Voicemeeter Config tab, turn on the Configure system audio toggle. Windows will use Voicemeeter Input for speakers and Voicemeeter Out B1 for the microphone.
  7. Let your games and chat apps follow Windows. Choose Default or System Default for their input and output devices. If an app requires specific device names, select Voicemeeter Out B1 for input and Voicemeeter Input for output; those manual selections will need changing when you stop using Voicemeeter.
  8. Start KeyboardSoundPlayer. Return to Home and click Start, or use the restart button if the player is already running. Wait for it to finish loading before playing sounds or capturing audio.

Keep Configure system audio on while using Voicemeeter. Windows will use it for your speakers and microphone. Turn it off before closing Voicemeeter to use the devices currently selected in Input Device and Output Device.

Keep Voicemeeter running while Output To Mic or Audio Capture is enabled. To use KeyboardSoundPlayer without Voicemeeter, turn Configure system audio off, set both features to No in Config, and click Save.

Audio Capture

Once you have followed the steps above on how to set up audio capture, you can follow these steps to start using the feature.

  • Set a Capture Key (the default is scroll_lock)When you press this key, KeyboardSoundPlayer clips the audio and automatically binds it to the next queued key.
  • Set Audio Clip Duration (Seconds) (the default is 3)This is the length of each captured audio clip.
  • Type a key in and press CaptureThis adds the key to the audio capture queue. Let's say you type a and hit Capture. This means that when you press your capture key (usually scroll lock), the audio will get bound to the a key. Now let's say you type a and hit Capture then you type b and hit Capture. This means that the first audio clip will go to a and the second will go to b.
  • Wait a few secondsThe audio clips take around 2-3 seconds to process after you press the capture key. It may even be longer for larger duration clips.
  • Have fun!Now that you understand how the feature works, go have some fun. You can use it to mess with people in game chat, or use it to clip something funny one of your friends said on a call.

Key Finder Tool

Press a key, and we will tell you what to type into KeyboardSoundPlayer. We do not support key combinations like ctrl+a. KeyboardSoundPlayer will just see it as two separate key presses. There is also no difference between uppercase and lowercase letters in KeyboardSoundPlayer.

Extra Information

To play a sound when any key is pressed, name the key "all". The GUI does not need to stay open for the sound player to function. The player can be shut off using the GUI or by pressing Esc 5 times quickly.
