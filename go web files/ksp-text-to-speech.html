Make a soundboard clip from text

Text-to-speech gives you a way to create spoken clips without recording your own voice or finding an audio file. Write a phrase, bind the generated audio to a key, and replay it whenever you need it.

  1. Choose a destination key. Enter the key that should play the spoken clip. If you are unsure of its name, use the Key Finder tool.
  2. Use Text. Select the Text button and enter the phrase you want KeyboardSoundPlayer to generate and bind.
  3. Start the player. On Home, click Start and wait for KeyboardSoundPlayer is ready.
  4. Play your phrase. Press the assigned key to hear the generated audio. Add other phrases on different keys to build a small speech soundboard.

Try a simple stream cue

Bind the phrase “Be right back” to a spare key. Add a second phrase, such as “Thanks for watching,” to another key. You can then replay either line with a single key press.

Adjust the voice and speaking rate

Open Config to change the settings used for autogenerated MP3 files:

  • Gender controls the gender of the generated voice. The documented default is male.
  • Rate controls the speaking speed. The documented default is 170.

Click Save to apply changes. Saving Config restarts the player if it is running, so wait for it to be ready again. Set your preferred voice options before generating a new phrase.

Start with a short line so it is easy to judge the speed and clarity. The full configuration reference lists these settings alongside playback, capture, and microphone options.

Play text-to-speech through your microphone

Generated speech can use the same output path as your other soundboard clips. For other people to hear it in a game or voice chat, enable Output To Mic and complete the Voicemeeter Banana microphone setup.

Your chat app must receive the virtual microphone. Test both your voice and a generated phrase before joining a call, so you know the selected input carries the sounds you expect.

Mix spoken phrases with other sounds

Use different keys for different sources: a generated phrase on one key, an MP3 or WAV sound effect on another, and a recent audio capture on a third. Text-to-speech is one way to add a sound to the keyboard, alongside the app's file, YouTube URL, and capture options.

Text-to-speech questions

Does the Text button also control the player?

Yes. It can bind text as generated audio or bind a function such as pause() or reset(). Use your spoken phrase when creating a voice clip, and a documented function when assigning a playback control. See the function reference for available controls.

Can I use a shortcut such as Ctrl+A for a phrase?

Bindings use individual keys. KeyboardSoundPlayer sees Ctrl+A as two separate key presses, and treats uppercase and lowercase letters the same.

Do I need Voicemeeter to generate spoken clips?

Voicemeeter is needed for microphone output and audio capture. You can generate and play text-to-speech locally with both of those features turned off.
