How soundboard microphone output works

Playing a clip on your speakers does not automatically send it to a voice chat. With Output To Mic enabled, KeyboardSoundPlayer uses Voicemeeter Banana to route soundboard audio through a virtual microphone that your chat app can select.

You need KeyboardSoundPlayer, Voicemeeter Banana, and your usual microphone and headphones or speakers. The steps below use the app's Voicemeeter Config tab to prepare the audio routing.

Set up Voicemeeter Banana for your soundboard

  1. Install Voicemeeter Banana. In KeyboardSoundPlayer, open Voicemeeter Config, click Download, and complete the installation. Restart your computer afterward.
  2. Enable microphone output. Open Config, set Output To Mic to Yes, and click Save.
  3. Select your devices. In Voicemeeter Config, set Input Device to your physical microphone and Output Device to your headphones or speakers. These selections save automatically.
  4. Check the application path. If Path to Voicemeeter Banana is empty or incorrect, use Select Path to choose voicemeeterpro.exe in the installation folder.
  5. Load the app's settings. Click Copy Settings Path, then Open Voicemeeter. In Voicemeeter, choose Menu → Load Settings on Startup, paste the copied path, and open the file. Restart Voicemeeter to load it.
  6. Enable Configure system audio. Turn this toggle on in KeyboardSoundPlayer. Windows will use Voicemeeter Input for speaker output and Voicemeeter Out B1 for microphone input.
  7. Start the sound player. Return to Home, click Start or restart the player, and wait for it to finish loading.

Use the soundboard in Discord, games, and calls

Let your chat app follow the Windows devices by choosing Default or System Default for its input and output. If you select devices manually, use Voicemeeter Out B1 as input and Voicemeeter Input as output.

In Discord, open User Settings → Voice & Video to check the input and output selections. Test a sound bound to a keyboard key and your voice before using the setup in a call.

If a clip is being cut off or sounds unclear, check your app's audio processing settings. Discord suggests testing with Noise Suppression disabled when troubleshooting audio quality; see its voice and video troubleshooting guide.

Keep Voicemeeter open while using this setup. Turn Configure system audio off before closing it. If you selected virtual devices manually in a chat app, change those selections back when you stop using Voicemeeter.

Microphone output troubleshooting

I can hear the soundboard, but other people cannot. What should I check?

Check that Output To Mic is set to Yes, Voicemeeter is running with the supplied settings, and your chat app uses the virtual microphone. An app set directly to your physical microphone will not receive the same routed audio.

Can I share captured audio and text-to-speech too?

Yes. Once those sounds are bound, you can replay them through the same microphone setup. Learn how to clip recent audio or create spoken clips from text.

Do I need Voicemeeter for local sound playback?

Voicemeeter is required for Output To Mic and Audio Capture. To use the player without it, turn Configure system audio off, set both features to No, and save Config.
